Нумерация документов ЭДО

Гибкая настройка номенклатуры по подразделениям и типам документов

Поле «Структурное подразделение» заполняется автоматически по отделу сотрудника из поля «от кого». Нумерация определяется по этому полю.

Когда заполняются поля в карточке

В настройках приложения вы только указываете, какие поля использовать. Сами значения в карточке смарт-процесса приложение записывает отдельно:

  1. Создаёте записку в Bitrix24 и указываете сотрудника в поле «От кого».
  2. Срабатывает триггер — робот автоматизации (webhook) или автоматический опрос раз в несколько минут.
  3. Подразделение — приложение определяет отдел сотрудника и записывает значение в поле «Структурное подразделение».
  4. Номер — сразу после этого присваивается номер по правилу подразделения и записывается в поле «Номер документа».

Без робота нумерация произойдёт при следующем опросе (по умолчанию каждые 5 мин) или по кнопке «Запустить опрос».

Как заполнить таблицу подразделений

  • Отдел Bitrix24 — отдел сотрудника из структуры компании (из поля «от кого»).
  • Название в карточке — текст для поля «Структурное подразделение», если поле текстовое.
  • Элемент списка — если поле подразделения типа «Список», выберите тот же вариант, что в карточке Bitrix24.
  • Тип поля подразделения: «Текст» — обычная строка; «Список» — поле с вариантами; «Привязка к отделу» — в карточку пишется ID отдела.

Как работает приложение

  1. В карточке укажите сотрудника в поле «от кого».
  2. Приложение определяет отдел сотрудника и подставляет «Структурное подразделение» по таблице настроек.
  3. Номер присваивается по правилу выбранного подразделения (префикс, формат, счётчик).
  4. Для каждого смарт-процесса в настройках видна вся таблица подразделений — можно добавлять и редактировать.
  5. Настройте робота: при создании или изменении элемента → HTTP на webhook (см. ниже).

Шаблон номера

          
Доступные переменные в поле «Формат»:

          
    
            
  • {prefix} — префикс
    • 
            
  • {suffix} — суффикс
    • 
            
  • {year}, {month}, {day}
    • 
            
  • {counter:4} — счётчик с дополнением нулями (4 цифры)
    • 
            
  • {department} — ключ подразделения
    • 
          

          
Примеры: {prefix}-{year}-{counter:4} → СЗ-2026-0001; {counter}зпг → 352зпг


          
Счётчики и пропуски в нумерации

          
    
            
  • Сброс — в таблице подразделений кнопка «Сброс» задаёт, с какого номера продолжить (поле «С»).
    • 
            
  • ↻ Синхронизация — сканирует документы на портале и выставляет счётчик по максимальному занятому номеру.
    • 
            
  • Пропуски — если включено, при удалении документа его номер будет выдан следующей новой карточке (например, удалили 360 → следующий получит 360, а не 361).
