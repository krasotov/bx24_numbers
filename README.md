# Нумерация документов ЭДО

Приложение для автоматической нумерации элементов смарт-процессов в цифровом рабочем месте «ЭДО».

## Возможности

- Автозаполнение поля «Структурное подразделение» по отделу пользователя-создателя
- Гибкая настройка правил нумерации по подразделениям и типам документов
- Режимы: автоматическая и ручная нумерация
- Настраиваемые префиксы, форматы, сброс счётчиков (год/месяц/никогда)
- Webhook для роботов автоматизации Bitrix24
- Фоновый опрос элементов без номера
